# 投机执行能力与验收边界

本文只描述当前实现、必须保持的契约和未完成项；已撤销方案、逐次功能版本及重复回归叙述不再累计。使用入口见[README](../README.md)，命令见[验证与消融](../bench/README.md)，研究资料见[Bash 复用研究](./bash-reuse-research.md)。

## 完整动作链路

预测或 Actor 入站 → 一次参数准备 → 不可漂移的 K(a)/执行绑定 → 候选索引与分层权限 → 安全执行与资源证据 → 等价转换和收益准入 → 事务采纳或单次 Actor fallback → 跨轮次保留与完整回收。

| 边界 | 当前职责与不可放宽的条件 | 主要实现 |
| --- | --- | --- |
| 预测与 Actor | Drafter、Actor probe、PatternAware 只产生来源中立动作；入站数据在异步排队和提供者回调前归属于本次调用 | [计划](../src/plan-runtime.ts)、[宿主接入](../src/agent-integration.ts) |
| 动作身份 | Pi preparation 只在 K(a) 前执行一次；语义、schema、参数、资源名称和执行身份不可后改；来源/调用编号/轮次不是等价条件 | [语义](../src/action-semantics.ts)、[工具绑定](../src/pi-tool-invocation.ts) |
| 路由与权限 | 唯一 Router 选择统一环境、本地安全后备、Actor；所选隔离路线不进入 K(a)，相同键也不授予执行或重放权限 | [执行世界](../src/execution-world.ts)、[执行网关](../src/tool-execution-gateway.ts) |
| 候选与调度 | 保存精确注册成员关系；动态资源版本属于产物证据；允许同一动作保留不同输入状态的结果 | [候选存储](../src/candidate-stores.ts)、[Runtime](../src/runtime-engine.ts) |
| 输入与输出 | 新参数在封存输入上求值，成功结果随同一候选有界保留；封存后不得新增输入，每次采纳仍验证新鲜度。默认不依赖工具输出投影 | [资源证据](../src/resource-version.ts)、[文件世界](../src/agent-execution-world.ts) |
| 进程与产物 | 完整进程身份、动态依赖、生产者保证及有序输出/效果分别封存；重放前验证并持有整个 CAS 闭包 | [进程后端](../src/linux-process-backend.ts)、[证书](../src/provenance-certificate.ts)、[存储](../src/reuse-store.ts) |
| 采纳与回退 | 再查权限、新鲜度、等价性、生产者保证和收益，然后提交；仅证明无效果的拒绝允许单次 fallback，poisoned 提交禁止重跑 | [事务](../src/effect-transaction.ts)、[调度](../src/scheduler.ts) |
| 关闭与保留 | 逻辑取消不等于物理完成；所有者拒绝新准入并等待已执行、借用、封存和清理，之后才能回收工作区 | [生命周期](../src/runtime-lifecycle.ts)、[工作区](../src/workspace-sandbox.ts) |

不得增加第二套 Router、事务、沙箱、进程协调器或缓存/CAS，也不以工具名、Bash 文本相似度、纯转发层或未经证明的宿主观察绕过上述边界。

## 跨平台当前能力

| 路线 | Windows x64 | Linux / WSL x64 | macOS / ARM64 |
| --- | --- | --- | --- |
| 封存输入上的原版 read/ls | 已验证；不提前运行任意 host function | 已验证 | 同一实现，但本机无真实 Runtime 验收 |
| 工作区 write/edit | Git 事务已验证 | Git 已验证；合格大树可选 OverlayFS | 仍需对应环境验收 |
| 原生 Actor 只读观察 | 路径绑定窗口无法证明，保持关闭 | 仅对具备完整稳定窗口证据的绑定开放 | 未据本机测试授予资格 |
| 受控 find/grep 与 TUI | 现有 rg 15.2.0 的显式共同 profile 已验证 | 现有 rg 14.1.0 的显式共同 profile 已验证 | 未资格化，不自动启用 |
| 原生 Bash 整体/子进程/in-flight | 不宣称原生 Windows 进程证书能力；WSL 是独立环境 | 按下表逐项探测和准入 | 需要真实 provider/helper 证明 |
| ThinkThread 可选接入 | 不虚构 Runtime | SDK/wire 接入回归保留；本机无真实 Runtime | 真实 Runtime 与 helper 配合未验收 |

本机 Windows 与 WSL 测试不是 macOS 或 ARM64 证明；本地 wire runner 也不是 ThinkThread Runtime。无安全路线时保留 Actor 正常执行，不把预测开关当作实际执行能力。

资源读取和目录枚举可能更新宿主 atime。描述符身份、路径包含、链接链和特殊文件检查保护输入语义，不提供宿主 metadata/审计事件零副作用保证，也不是恶意并发换成设备文件的内核隔离。不得事后恢复时间戳来掩盖这一边界。

Windows 的目录/junction A→B→A 可能保留 inode 与时间戳，因此仅内容相等不能认证 Actor 未读到中间状态。watcher 只能否定不稳定窗口，不以没有事件代替精确输入证明。

## 受控搜索

Native Pi 始终是默认。TUI 的 Captured search 必须在 Apply 后共同绑定 Actor 与投机；配置、HOME、固定引擎字节和已准备参数属于执行身份。缺少 rg 不关闭受控 find；不安装新的搜索依赖或引擎。

find 使用 Pi 已有匹配/ignore 组件。grep 按路径排序并禁用环境 rg/全局 Git ignore 配置，仍捕获具名祖先/Git 配置；这不是原生默认等价。原版 Pi 的格式化、编码处理、上下文回读、退出和截断全部属于资格范围，不能仅跟踪 rg 而漏掉 Pi 回读。

生产者与 Actor 共用现有受控输入协议，输入按需计费并由调用持有。未知输入不能伪装成 ENOENT；ignored 和 negative-glob 子树不能被无故遍历。输入/结果预算分别为 8 MiB/1 MiB，五秒请求期限包含启动；取消、结果超限和池退休必须等待进程/流关闭及输入清理。

当前两端各 46 个小型语义案例与生产 TUI 的完成、跨轮次、重算、running join、变更 miss、单次 fallback、关闭排空已验证。断裂目标、跨卷输入、cwd 别名和 glob 组合尚不具备一般资格。语义通过不代表每次有收益，仍由既有收益门决定采纳。

## Bash 的依赖分层

必须分别判断：消费已封存结果、观察已获 Actor 授权的执行、在 Actor 授权前启动未命中。它们共享证书与事务，不共享无条件的执行许可。

| 依赖或机制 | 提供的能力 | 缺失后的降级 |
| --- | --- | --- |
| 证书、内容哈希与 CAS | 验证历史依赖和不可变产物闭包 | 无可复用历史，Actor 正常执行 |
| 精确工作区事务 | 验证 before-state 并原子应用 after-state | 带文件副作用的证书不能接管 |
| held exec / ptrace / 所需 FD 权限 | 在真实子进程第一条用户态指令前形成替换边界，当前仅 x86-64 Linux | 失去子进程重放/加入及当前共用此边界的完整生产路径；整条命令消费保留 |
| 完整进程观测 | 动态依赖、效果和每个相关进程的最终退出记录；父退出不能掩盖未结束子进程 | 不能生产严格进程证书；已有证书仍可消费 |
| 合格 Sandlock/Landlock/seccomp | 允许在 Actor 前执行未命中并约束副作用 | 不得冷启动 Bash 投机生产者 |
| Git | 当前完整生产路径的私有工作区 | 不能启动该生产路径；已有证书消费仍可保留 |
| FUSE OverlayFS | 降低特定大目录树的分支/物化成本 | 使用 Git，验证与权限条件不变 |

strace 不是提前执行许可，Landlock 也不是输入证据。当前 Sandlock 不新建 user/PID/mount namespace，保留 Actor 原生身份与可见 PATH；只把私有工作区映射到逻辑源码路径，并拒绝常见凭据目录和证书存储。观察到不同隔离状态的结果不得直接跨入 Actor 域。

证书是否可接受取决于当前格式、平台、可执行字节、argv、cwd、环境、stdin/FD、资源、before-state、生产者保证和消费者契约。只有当前契约的证据才能使用，不转换旧格式；查询不清库，文件仍由既有 GC 管理。没有合格生产者且只有不被接受的旧数据，不会获得预热或收益。

### 尚未完成的 Actor 观察层

已完成命令消费不解析 Sandlock/strace binary，Actor 子进程边界也能在 miss 后继续原子进程。新证书生产仍来自完整 Linux 投机生产者，独立的 Actor-authorized 进程 observer 尚未接入。

目标是：无 Landlock、但有足够观测与精确事务证明时，Actor 第一次正常执行并产生证书，之后可以消费；仍不得在 Actor 授权前启动 miss。这个目标不能用已有消费命中或通用 Observe 接口代替。

证据还必须覆盖 Actor 实际消费的宿主字节。普通 strace 和工作区 delta 不能自动排除 A→B→A、mmap、动态链接器等观察缺口；只记录时间或拿隔离分支的事后快照不算完成。不为通过测试增加较弱 observer。

### 共同等价性契约

接管同时验证五类事实：

1. 语义身份：可执行摘要、argv、cwd、环境、stdin/FD、凭据、限制、信号和平台。
2. 动态依赖：被准入的文件内容/元数据、目录、负查询、链接解析及其他输入。
3. 结果事务：有序 stdout/stderr、退出状态、精确工作区 before → after 转换。
4. 生产者保证：观测完整性、执行授权、隔离与输出控制。
5. 消费者契约：当前接管路径接受的保证、副作用与一次性范围。

网络、IPC、设备、交互式描述符、未建模 ioctl、跟踪丢失、逸出子进程以及时间/随机数/PID 等输入必须被完整拒绝、虚拟化或捕获；否则只能使用严格的一次性结果，或拒绝采纳。依赖减少不代表条件变宽。`| tail -n 20` 等 shell 文本不是投影证明。

### Actor 路由与生命周期

1. 调用到达时先查并验证可消费的整条命令证书，命中才原子接管。
2. helper 可用时，在真实 exec 边界查子进程证书或同轮运行中工作；未知 Actor 耗时沿用统一等待策略，miss 让原子进程继续一次。
3. 独立 Actor observer 完成前，不把上述 miss 算作新证书生产。
4. 只有完整 producer 探测和权限通过，才允许在 Actor 到达前执行未命中。
5. 干净拒绝最终落到原 Actor；已经可能执行过的 broker 请求遇到响应丢失时返回错误，不能再跑一次。

进程消费者共用已绑定原型生成的 weakKey；弱键只定位候选，封存记录与 CAS 各自持有捕获输入。一次性父子结果共享消费权，异步验证后仍检查互斥；子进程先采纳则父分支不能再整体提交，整体提交先取得消费权则子进程不能再接管。只有明确回滚成功才恢复资格，可重复证书仍可复用。

会话停止准入并取消执行，随后排空进程树、broker、封存与输入/输出操作，再回收工作区。helper 保留父退出状态但等待后代；helper/strace 使用内核退出联动终止独立进程组中的 tracee，异常路径也先回收。当前 helper 协议和生产者资格拒绝旧实现及旧证书。资源指纹与 GC 失败仍排空同伴；临时文件仅在独占创建成功后取得清理权。

工作区捕获在首次变更区间才初始化。开始后发生 trace 目录分配失败也须 abort；重叠区间、时钟不前进、类型或 inode 语义不支持时禁止发布。精确不可变基线和稳定描述符字节才是内容权威，时间戳只筛选候选路径。

Sandlock 的 ELF 分类不消耗脚本 FD；只有 ELF 才进入解释器解析，资格检查真实短脚本退出状态。已安装 binary 不合格则不可作为 producer，不能用测试结束标记掩盖脚本前缀丢失或 worker 错误。

OverlayFS 必须通过固定 binary、FUSE、copy-up、whiteout、opaque、匿名事务时钟及卸载全生命周期探测；精确基线达到 256 项才自动选择。驱动不支持结果污染证据；无法证明已卸载的活挂载隔离保留，不删除其存储。不同 world 只回收自身资源。

## 必须保留的验收矩阵

每种依赖组合都区分空存储与预置可接受证书。同机器、同初始快照比较 Direct / Trace / Publish / Whole-hit / Child-hit / Child-join / Fork-miss / Fork-hit：

| 消融 | 初始条件 | 必须证明 |
| --- | --- | --- |
| 完整路径 | 空存储 | 安全生产证书，后续整体/子进程消费 |
| 去掉 FUSE | 空存储 | Git 保留正确性，只改变性能 |
| 去掉 Landlock | 预置证书 | 整体及 held-exec 子进程消费；不得把生产依赖藏在测量外 |
| 去掉 Landlock | 空存储 | 当前直接执行且不生产；自预热是未完成目标 |
| 去掉 strace | 预置证书 | 可消费，不发布新证书 |
| 去掉 helper | 预置整条命令证书 | 整体消费保留，子进程复用消失 |
| 去掉 Git/FUSE | 无副作用或可直接提交证书 | 消费路径不意外依赖分支创建工具 |
| 改变动态输入 | 预置证书 | miss，且 Actor 恰好执行一次 |

每行比较完整输出、退出状态、最终工作区和真实执行次数，分别报告查询、验证、等待、执行、封存与接管成本及命中/污染数。重复历史证书只共享同一路径集的当前捕获，不省略角色、元数据、负查询父目录或排除项。

各可执行工具保留 completed、running join、输入改变 miss、取消和失败后 fallback。原生 Bash 另需同父/跨父复用、完整输出的并发 barrier、发布竞态、效果回滚和进程关闭。测试优先重构已有条目，不增加只为通过测试的生产接口。

## 当前证据与剩余工作

- 从干净的 `8c559d1` 开始；2026-09-09 的 check/test/build/bench:check 两端通过，53 文件、547 项：Windows 531 通过/16 跳过，WSL 546 通过/1 跳过。使用已有合格 Sandlock 与仓库外当前 helper；未替换默认安装或放宽探测。
- 固定口径含空行：`src` 32,488 → 32,454 行，`test` 14,821 → 14,651 行；字节分别增加 1,022/2,615，随包脚本 269 行未变。父子互斥与竞态覆盖使本阶段增长，虽已合并重复检索出口，减量要求仍未达到。较 `485cdb2` 生产字节多 21,179，30,411 行绝对预算仍差 2,043 行。
- 既有 tape/构造流覆盖竞胜、失配、续推、取消和跨轮；未知 Actor 耗时下连续命中仍保留探索，新增付费 API 请求为零。PatternAware 每平台 144 组、3,024 个候选及快照一致，微基准约 1.38–1.64 倍，不代表整任务收益。
- 完整 Actor 路线完成 9 场景 × 开/关 × 3 轮，含首次资格和回收，中位数：就绪 14.513 → 10.537s，整项 in-flight 7.004 → 6.241s，父命令失配后的子进程接续 7.004 → 6.141s，跨父带输入复用 7.004 → 6.017s。输入变化退化至约 10.11–10.21s，冷到达略慢；开启侧约多用 1.6–2.9s CPU。任务使用固定历史和 4s 原生等待，输出逐对一致且 fallback 恰好一次，不外推自然模型收益。
- 随机输出真机回归确认整项与子进程不再重复消费；原生计算、元数据拒绝、跨轮和取消仍通过。旧 42 次 Bash 对照仅装配整项消费者，不能代表完整 fallback。`b511029` 的 132 次共同 Captured search 对照中，提前窗口和部分输入复用有收益，冷到达/小输入热重复无稳定收益；Native Pi 默认语义与自然模型性能不在此证据内。
- 独立 Actor 进程观察、减量预算、macOS/ARM64、真实 ThinkThread Runtime 及自然应用验收仍未完成。

历史性能报告的条件与复现入口统一放在[验证说明](../bench/README.md#已保存的历史测量)。它们是历史实测，不替代当前提交的完整资格。
