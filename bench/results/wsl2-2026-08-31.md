Each fresh run compiled a child executable that sleeps for one second, reads
`input.txt`, writes `artifact.txt`, and emits ordered stdout/stderr. The second
Bash command had different parent text but the same child exec prototype. It
recorded exactly one hit, zero misses, zero bypasses, and zero taints; child
output and the regular-file effect matched the cold execution. Changing
`input.txt` before the third parent produced exactly one miss and the new
`beta` output/effect. Every outer branch passed exact freshness validation
before commit.

The fixed isolation cost remains visible: the hit still materializes a Git
branch, mount namespace, trace, and adoption evidence. Thus this substrate is
profitable for child work above that fixed cost, while the scheduler should
continue to suppress low-value speculation. When a prediction is already
complete at Actor interception, the foreground adoption path in these runs was
only validation plus commit (roughly 14–17 ms); the 684 ms hit total is
background speculative work, not mandatory foreground wait.
