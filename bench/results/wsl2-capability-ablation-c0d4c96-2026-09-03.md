# WSL2 Bash 复用依赖降级消融记录

实现版本：`c0d4c96`；进程/exec 行在 `4affb64` 上测量，运行中子进程准入行在 `945497a`
上重新测量，顶层运行中结果行在所有权重构后重新测量。

主机环境：WSL2 上的 Ubuntu 24.04、Linux 6.18.33.2、x86-64、Node 24.20.0、
Sandlock 0.8.6、strace 6.8。源码、工具和临时工作区均位于 WSL 原生文件系统。跟踪相关行
执行 20 次。结果用于验证各项依赖负责的能力，不代表任意任务上的普遍加速比。

## 核心结论：无 Landlock 到底还能做什么

本次消融已经证明：**只要存储中预先存在兼容证书，消费结果不需要 Landlock，也不需要
`strace`**。在故意把这两个生产者二进制都设为不存在后，原生 held-`execve` 消费路径仍把
226.55 ms 的子进程直接执行缩短到 27.84 ms，即 **8.14x**。

但这不等于“没有 Landlock 的空机器能自行加速”。当前实现仍把新证书生产绑定在完整
Sandlock + `strace` 路径上。因此：

- **已有兼容证书**：可重放整条命令；x86-64 held-exec 可用时，还能跨不同父 Bash 重放子进程。
- **空存储或依赖已变化**：安全未命中并正常执行 Actor 命令，当前不会生成新证书，因此没有后续加速。
- **只有 `strace`、没有 Landlock**：理论上足以观测 Actor 已授权的执行，但当前尚未拆成独立生产路线。
- **缺少的只有 FUSE OverlayFS**：不降级安全能力，改走 Git 工作区事务。

所以目前无 Landlock 层的准确名称是“**可消费的安全降级层**”，而不是“低隔离生产层”。

## 已测量的依赖消融

每一行都是生产路径的端到端运行；命令、初始状态和输出正确性要求保持一致。

| 消融目的 | 保留/移除的机制 | 本机结果 | 能证明什么 |
| --- | --- | ---: | --- |
| Actor 基线 | 移除全部 Bash 复用 | 1 s 工作负载 1009.65 ms | Actor 反事实 |
| 查询开销 | 保留已完成结果存储，但没有匹配证明 | 1014.62 ms；+4.97 ms（噪声量级） | 安全未命中不会重复执行，查询开销很小 |
| 单独观测 | 仅保留普通 `strace` | 1024.02 ms；+14.36 ms / 1.014x | `strace` 能记录证据，但没有权限替代第二次执行 |
| 无生产者依赖的已完成子进程消费 | 预置证书；保留存储和原生 held-`execve` 代理；故意移除 Sandlock 与 `strace` | 27.84 ms，对比直接执行 226.55 ms；**8.14x** | 已完成结果的命中路径不依赖 Landlock/`strace`；不证明空存储可自预热 |
| 运行中子进程接管 | 完整生产者 + held-exec + 实测成本准入 | 68.83 ms，对比直接执行 213.01 ms（提前 400 ms）；**3.09x**，节省 144.17 ms | 合格生产者存在时，可在剩余工作加接管成本更低时加入 |
| Git 完整生产路径 | Sandlock + `strace` + Git 事务 | 冷执行 2971.63 ms；跨父 Bash 子进程命中 1897.94 ms，相对冷执行 **1.57x** | 不依赖 FUSE 仍能安全生产和命中 |
| FUSE 存储性能消融 | 完整生产路径，把 Git 分支物化替换为 FUSE OverlayFS | 冷执行 3090.93 ms；跨父 Bash 命中 1714.24 ms，相对冷执行 **1.80x** | FUSE 只改变性能，不增加证明权限；小目录结果不能确定存储赢家 |
| 顶层运行中接管 | 完整生产者 + Runtime 管理的一次性分支 | 2614.85 ms，对比直接执行 4009.66 ms（提前 3 s）；**1.53x**，节省 1394.81 ms | 同一预测周期内可接管一次带 PID 污染的精确执行，不进入持久历史 |

已完成子进程消费行还改变了输入：证书随即未命中，被暂停的 Actor 子进程只继续执行一次。
这同时验证了“无生产依赖命中”和“输入变化安全回退”，不是仅测一条理想命中路径。

## 哪些降级结论是实测，哪些只是当前代码行为

| 机器状态 | 当前结果 | 证据状态 |
| --- | --- | --- |
| 无 Landlock + 预置兼容证书 + held-exec | 可跨父 Bash 消费子进程证书 | 已实测，8.14x |
| 无 Landlock + 预置兼容整条命令证书 | 可在 shell 启动前重放 | 单元/集成路径已覆盖；本记录没有单独的 WSL 延迟行 |
| 无 Landlock + 空存储 | 查询后直接执行，不发布新证书 | 当前代码行为；尚无独立延迟行 |
| 无 Landlock + 有 `strace` + 空存储 | 与上一行相同，因为 Actor Observe 尚未独立接线 | 当前代码行为，也是下一项结构性缺口 |
| 无 `strace` + 预置兼容证书 | 仍可消费已有证书 | 已由同时移除 Sandlock/`strace` 的命中行实测 |
| 无 held-exec + 预置整条命令证书 | 整体命令仍可重放；跨父 Bash 子进程复用消失 | 单元/集成路径已覆盖；本记录没有单独的 WSL 延迟行 |
| 无 FUSE、保留 Git | 完整生产与复用能力保留 | 已实测，Git 行 |
| 原生 Windows | 当前不消费或生产 Linux Bash 证书；WSL 可作为独立 Linux 平台使用 | 不属于本次 WSL 消融 |

特别需要避免一种错误解读：8.14x 行先用完整合格生产者生成证书，再在消费阶段移除依赖。
它证明的是生产/消费解耦，而不是 Landlock 对生产阶段不重要。若报告“无 Landlock 加速比”却不
写明存储已预热，就会把完整生产阶段的成本和依赖隐藏起来。

## 其他机制消融

### 观测边界

syscall 密集型微基准中：直接执行 5.81 ms；仅监听 exec 事件的 Actor 代理 5.63 ms；普通
过滤 `strace` 490.90 ms；启用 `--seccomp-bpf` 的 strace 8.08 ms。快速模式仍只作为消融项：
更高优先级的 seccomp 决策可能隐藏生产证明必须观察到的 Sandlock 拒绝。改善数字但削弱证据，
不能进入严格生产路线。

### 目录 FD 覆盖

`709a2ff` 覆盖探针让 helper 保存 cwd 的目录 FD、切换到 `/`，再通过 `fchdir` 返回后执行
有效工作。直接执行 1007.91 ms，冷 Fork 2773.72 ms，跨父 Bash 子进程命中 1610.54 ms
（相对冷执行 **1.72x**）。生产解析、封存、跨父 Bash 重放和输入变化未命中仍全部有效，没有
增加命令特定策略或第二条 benchmark 路径。

### 运行中准入

运行中子进程重测先强制制造同类输入变化的 Actor 未命中。原生 exec 边界上报该子进程的真实
执行时间；共享调度器再比较 Actor 时间的较低分位数与“投机剩余时间 + 接管成本”的较高分位数。
没有 Actor 样本时，Linux 零等待恢复子进程并学习，不在关键路径上盲等。学习模型估计节省
134.30 ms，实测反事实节省 144.17 ms。更早一次没有 Actor 样本的已完成命中只报告命中，
没有虚构节省时间。

## 正确性门槛

所有计时行都要求输出、退出状态和最终文件与 Actor 直接执行完全相同，并通过：

- 输入变化、跨轮次运行中/已完成候选与一次性认领；
- 继承描述符、完整 stat 元数据、目录 FD 与可观测隔离差异；
- 产物损坏、跟踪不完整、代理丢失、超时和提交失败；
- 网络、IPC、随机数、时间、PID 等不能被当前证明完整控制的资源。

Windows 与 WSL 均通过当时全部 464 项单元/集成测试。污染顶层 Bash 的描述符、PID 和随机
输入没有被放宽，因此这类执行不会产生持久整条命令证书。

## 下一轮必须补齐的消融

要验证真正可用的依赖阶梯，还需要增加以下独立行：

1. **无 Landlock、空存储、保留 `strace` 与精确事务**：当前应直接执行且不发布；拆出 Actor
   Observe 后应第一次执行、第二次命中，但始终禁止提前执行未命中。
2. **无 held-exec、预置整条命令证书**：证明整体重放完全不依赖 ptrace helper。
3. **无 Git/FUSE、预置无副作用证书**：证明纯消费路径不意外依赖工作区分支创建。
4. **同一组任务分别使用空存储与预热存储**：生产成本、消费收益和稳态收益必须分别报告。

这些新增行不能通过放宽证书、删除污染标记或允许未隔离提前执行来制造命中。
